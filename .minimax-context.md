## What this project is

The MORISTACK apex (`moristack.com`) brand hub. A small Next.js 16 site that:

- Lives at the `moristack.com` apex (English-only, no locale switch).
- Replaces the previous "Choose your language" stub that was served by the
  `call` project as a domain alias.
- Lists the MORISTACK products (currently `plan.moristack.com` and
  `call.moristack.com`) and gives the brand a real About / Services / Contact
  surface.
- Receives requests via `/request` and forwards them through Resend to
  `support@moristack.com`.

## Stack

- Next.js 16.3, App Router, React 19.2
- TypeScript 5, Tailwind CSS 4
- `@vercel/analytics` + `@vercel/speed-insights` for site-wide traffic
- Resend (transactional email from `/api/request` to `support@moristack.com`)
- No database, no Stripe — this site is content-only plus one email route

## Content model

`lib/content.ts` is the single source of truth for user-facing copy. To
add or retire a service, edit the `services.items` array. To change the
hero, about, founder, footer, or guides copy, edit the corresponding
`content.<section>` field.

`contactEmail` is exported as `CONTACT_EMAIL = "support@moristack.com"` and
must be the only contact address used anywhere on the site.

## SEO

- Sitemap at `/sitemap.xml` covers all public pages
- Organization + WebSite JSON-LD in `app/layout.tsx` (renders in React tree,
  visible to modern Googlebot)
- `alternates.languages` in root layout (`en` and `ja-JP` both → `/`)
- OpenGraph + Twitter cards in root layout
- Canonical URL on every page
- Generated OG image at `/opengraph-image`

## Conventions

- All copy is English-only — no bilingual variants
- Components use Tailwind classes mapped to CSS variables defined in
  `app/globals.css` (`--color-fg`, `--color-fg-soft`, etc.)
- Brand voice: no legal entity, no location, no team/one-person framing,
  no numeric enumeration of services. Contact is `support@moristack.com`
  only — do not invent new email addresses.

## What to avoid

- Don't add a database. The site is meant to be deploy-and-forget.
- Don't duplicate product copy from `plan` / `call` — keep this site
  high-level and link out.
- Don't commit secrets. Vercel env is the only place for keys.
- Don't add POKO references — POKO is intentionally excluded from the
  MORISTACK brand surface.
