## What this project is

The MORISTACK apex (`moristack.com`) brand hub. A small Next.js 16 site that:

- Lives at the `moristack.com` apex and `/ja`, `/en` locale roots.
- Replaces the previous "Choose your language" stub that was served by the
  `call` project as a domain alias.
- Lists the MORISTACK products (currently `plan.moristack.com` and
  `call.moristack.com`) and gives the brand a real About / Services / Contact
  surface.

## Stack

- Next.js 16.3, App Router, React 19.2
- TypeScript 5, Tailwind CSS 4
- `@vercel/analytics` + `@vercel/speed-insights` for site-wide traffic
- No database, no Stripe, no Resend — this site is content-only

## Layout

```
src/
  app/
    layout.tsx            # root layout (apex / no Header/Footer)
    page.tsx              # language gate: "Choose your language" + service list
    sitemap.ts            # all 9 URLs (apex + 2 locales x 4 sections)
    robots.ts             # allow all, disallow /api
    not-found.tsx         # 404 with links to /, /en, /ja
    [locale]/
      layout.tsx          # locale layout: Header + Footer + Organization JSON-LD
      page.tsx            # home: hero + service cards
      about/page.tsx
      services/page.tsx
      contact/page.tsx
  components/
    Header.tsx            # logo + nav + locale switch
    Footer.tsx            # copyright + nav
    ServiceCard.tsx       # used in /[locale] and /
  lib/
    services.ts           # SERVICES list (id, name, tagline, oneLiner, url, status)
    i18n.ts               # LOCALES, Locale type, isLocale
```

## Content model

`lib/services.ts` is the single source of truth for the product list. To
add or retire a service, edit the `SERVICES` array. Each service has
both `en` and `ja` one-liners.

`status` field is reserved for future filtering (e.g. "live" / "wip" /
"planned"); the home page currently shows all services.

## SEO

- Sitemap at `/sitemap.xml` covers apex + all 8 locale routes
- Organization JSON-LD in `[locale]/layout.tsx` (renders in React tree,
  visible to modern Googlebot)
- `alternates.languages` in root and locale layouts
- OpenGraph + Twitter cards in root layout
- Canonical URL on every page

## Conventions

- All copy is bilingual — never edit only one locale
- Components use Tailwind classes mapped to CSS variables defined in
  `app/globals.css` (`--color-fg`, `--color-fg-soft`, etc.)
- Apex (`/`) intentionally shows the language gate + service list; do
  not replace it with a redirect without coordinating with SEO

## What to avoid

- Don't add a database. The site is meant to be deploy-and-forget.
- Don't duplicate product copy from `plan` / `call` — keep this site
  high-level and link out.
- Don't commit secrets. Vercel env is the only place for keys.
